# Política de Privacidade — ChimpBot

**Última atualização:** 24 de agosto de 2026

Sua privacidade é importante para nós. Esta política descreve quais dados são coletados pelo **ChimpBot** e como eles são processados e armazenados.

---

### 1. Dados Coletados
O ChimpBot coleta apenas as informações estritamente necessárias para o funcionamento dos seus sistemas de RPG, economia e atribuição de cargos:

* **IDs do Discord:** Guardamos o ID numérico do usuário, ID do servidor (Guild ID) e ID de canais para associar o progresso do jogo (nível, bananas, tribo e inventário).
* **Nomes de Usuário:** Armazenados temporariamente para exibição em rankings e perfis dentro do bot.
* **Logs de Comandos:** Registros de interações com o bot para auditoria de erros e prevenção de abusos.

*O ChimpBot **NÃO** coleta, lê ou armazena conteúdo de mensagens privadas ou conversas de texto do servidor.*

### 2. Uso dos Dados
Os dados coletados são utilizados exclusivamente para:
* Manter o histórico de inventário, moedas e estatísticas do usuário no bot.
* Processar comandos executados pelos membros.
* Garantir o funcionamento correto dos cargos de tribos e moderação.

### 3. Armazenamento e Segurança
* Todos os dados são armazenados de forma segura em banco de dados com acesso restrito à equipe de desenvolvimento.
* Nenhum dado coletado pelo ChimpBot é vendido, compartilhado ou transferido para terceiros.

### 4. Retenção e Exclusão de Dados
* Os dados do usuário permanecem salvos enquanto ele utilizar as funcionalidades do bot.
* Se um servidor remover o bot, os dados associados àquela guilda podem ser purgados periodicamente.
* **Solicitação de Exclusão:** Você pode solicitar a remoção completa dos seus dados armazenados em nossos bancos de dados a qualquer momento entrando em contato com a equipe de suporte no servidor oficial.
